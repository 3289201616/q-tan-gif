HOW TO Q

怎么揉出最好吃的 Q 弹

01

导入主角

图片支持裁剪与缩放；3D 模型支持 GLB / GLTF / FBX / OBJ / STL / PLY / 3MF / DAE / 3DS / USDZ，多文件或 ZIP 都可以。所有素材只在浏览器本地处理。

02

调到心动

上下伸缩、压扁、节奏、摇摆都能调，滑杆上限最高到 300，伸缩节奏最高 6×。3D 模型默认自动 360° 旋转，速度可选 1–6 圈/循环，也可以左右拖动环视。

03

导出无缝 GIF

所有运动都以完整周期计算，最后一帧会自动接回第一帧。导出后会弹出预览，确认满意再保存。
